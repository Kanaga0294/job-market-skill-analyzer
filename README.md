# Job Market Skill Analyzer

## Overview

A Python-based data structures project that analyzes skills requested across job postings for data and analytics roles.

## Features

- Stores job posting data using dictionaries and lists
- Adds new job postings interactively
- Cleans and normalizes skill data
- Extracts and counts skills
- Displays top skills by frequency
- Calculates basic statistics
- Searches jobs by skill
- Uses lambda and filter
- Generates CSV and TXT output files

## Technologies

- Python
- Google Colab / Jupyter Notebook
- GitHub

## Project Files

- `Job_Market_Skill_Analyzer.ipynb` — Main Python assignment notebook
- `job_skills.csv` — Cleaned job posting data
- `top_skills.txt` — Top skills and their frequency
